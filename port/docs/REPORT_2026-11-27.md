## Gotchas

- `lib_ab.sh` reads stdin: in a shell loop it ate the loop's input and the next runs did nothing. Use `< /dev/null`.
- A GPU library build that changes renderer or recompiler sources gets a new cache key: the next start precompiles
  in full (and then counts the driver's cache as warm).
