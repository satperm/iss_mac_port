## Native Metal (spike day 1)

On the truck (82 FPS) the GPU is ~60% busy: idle 40% = 20% short gaps inside command buffers (encoder switches),
14% starved (the CPU side is late), 6% started late. The encoding thread is 80% busy, MoltenVK's own part ~1/3 of
it. The frame is set by the CPU chain (the game's ~7 ms under Rosetta, then the wait for the GPU particle chain).
Expected gain at 1080p +5-10% for 4-6 weeks: not now; revisit for 1440p+/GPU-bound Macs.
